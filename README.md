# China 2027

Web estatica simple para comparar tres rutas de viaje por China en 2027.

## Archivos

- `index.html`: estructura principal
- `styles.css`: diseno y responsive
- `script.js`: cambio entre rutas

## Uso

Abre `index.html` en el navegador.

Si mas adelante quieres publicarla en GitHub Pages:

1. Sube esta carpeta a un repositorio.
2. Activa `Settings > Pages`.
3. Elige `Deploy from a branch`.
4. Selecciona `main` y la carpeta raiz.

## Nota

Las tarjetas visuales usan imagenes remotas para esta primera version local. Si quieres, el siguiente paso puede ser sustituirlas por imagenes descargadas y dejar el sitio totalmente autonomo.
